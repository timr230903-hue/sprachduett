# Sprachduett

Thai zu zweit. Jedes iPhone zeigt nur die eigenen Zeilen. Die andere Person hört zu und antwortet laut.

- iOS 17, SwiftUI, Deutsch
- Bundle `de.timroot.sprachduett`, Team `3YVJ6AK57U`
- CloudKit-Container `iCloud.de.timroot.sprachduett`
- Fachkern: `swift test`

Projekt erzeugen, wenn XcodeGen installiert ist: `xcodegen generate`. TestFlight-Workflow: `.github/workflows/testflight.yml`. Aufbau und spätere Runden: `docs/ARCHITEKTUR.md`, `docs/ROADMAP.md`.
